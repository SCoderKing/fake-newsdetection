About the Programme

Fake News Detection & Media Literacy Programme


The purpose of this CEP project is to create awareness about misinformation and encourage responsible digital communication.


The website provides educational information, a basic warning-sign checker and an interactive media literacy quiz.


Project Objectives


✔ Understand misinformation

✔ Identify common warning signs

✔ Encourage source verification

✔ Promote responsible sharing

✔ Improve digital media literacy
